# ⚠️📈 Quarto Projeto - Controlede nível de reservatório de água

Este projeto tem como objetivo o monitoramento de um reservatório de água.

##  💻⚙️Objetivo

Praticar lógica de programação para praticar o ciclo **Entrada &#10230; Processamento &#10230; Saída** considerando a aplicação de operadores relacionais, prática da indentição aninhada, e combinação de ideias utilizando os operadores e if/elif/else e match/ case, listas, funções, bibliotecas internasdo python e inportação e utilização da bibliteca colorama.

## 🐍 Linguagem usada (Python)

## 🔴🟡🟢🔵🟣 Analise e Resultados

O programa através da biblioteca randon importada do python escolha de um dos niveis de agua de um reservatório constante de uma lista (Nivel 1, Nivel 2, Nivel 3, Nivel 4 e Nivel 5) e a cada um desses niveis é atribuida situação. O programa eibe essa situação referente ao nivel escolhido de acordo com um padrão de cores pré estabelecido para cada nivel, utilizando a biblioteca colorama importada externamente com o pip.
